# TOMORROW'S YOU — Android Alpha 0.1.0

TOMORROW'S YOU is an Android temporal puzzle adventure where your previous attempts become teammates.

## Features

- Record attempts as Echoes that replay alongside you and expire after their recorded duration.
- Coordinate pressure plates, logic doors and sequence mechanisms across ten campaign levels and five difficulty tiers.
- Manage a shared, level-specific WAIT allowance.
- Discover MORROW transmissions and the Incident Archive.
- Use three daily hint credits, with free review of already revealed hints.
- Local saves and offline-first gameplay; no account required.

## Public alpha notice

This is an early testing version. Bugs, balance issues and compatibility problems may remain. This release is distributed as an APK through GitHub Releases, not Google Play.

## Known issues

- Movement timing loops can bypass intended WAIT strategies. Current allowances are verified for intended shortest routes, not unrestricted global minima.
- Nightmare has a known two-Echo sequence-latch solution despite its intended three-Echo design.
- Device compatibility and real-device lifecycle/offline testing remain pending for this release candidate. Automated desktop tests do not replace Android playtesting.

## Android requirements

The verified release-candidate manifest requires Android 7.0 / API 24 or newer. The prepared preset includes ARM64, ARMv7, x86 and x86_64. Vulkan/mobile-renderer support may further restrict compatibility; no universal device support is claimed.

## Installation

1. Download the signed `TomorrowsYou-v0.1.0-alpha.1-android.apk` and its matching `.sha256` file from this prerelease's assets.
2. Compare the APK's SHA-256 with the checksum file. On Linux, run `sha256sum -c TomorrowsYou-v0.1.0-alpha.1-android.apk.sha256` in their directory.
3. On Android, temporarily allow APK installation from the browser or file manager used to open it.
4. Open the APK and follow Android's prompts. Disable that install permission afterward if desired.

If Android reports a signature conflict with an existing development/debug installation, stop. Do not uninstall or clear data unless you have separately backed up progress and accept the risk of losing it. A release key cannot update an installation signed with a different debug key. Back up your release signing key privately; later releases must retain the same package ID and signing identity to support normal updates.
