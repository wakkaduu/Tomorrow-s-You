# TOMORROW'S YOU — Android Alpha 0.1.0-alpha.2

Preparation only: **unpublished; final signed APK runtime QA pending**.

This candidate corrects four Android QA findings from alpha.1:

- System Back follows modal and menu navigation, with an exit confirmation on Main Menu. Settings and Archive return to the originating screen while preserving a paused puzzle.
- Android selects the OpenGL Compatibility renderer automatically. Temporal backgrounds, holographic effects, particles and Echo trails are retained. This avoids the tested emulator Vulkan presentation failure; it does not establish that Vulkan itself is fixed.
- Solution scoring counts the current attempt and committed Echo recordings. Discarded attempts and completed-level replays no longer inflate the next score; historical best results are preserved.
- Board layout changes reposition actor animation endpoints, interpolated visuals and Echo trails without changing puzzle state.

Package: `com.tomorrowsyou.game`. Version: `0.1.0-alpha.2`, Android versionCode `5`. Updates must retain alpha.1's permanent signing certificate and schema-3 save data.

The campaign, story, level-specific WAIT budgets and daily hint allowance are unchanged. Known balance limitations remain: movement loops can replace intended WAITs, and Nightmare has a two-Echo sequence-latch shortcut. See the QA and WAIT balancing reports.

Internal testing covers Android 15/API 35 x86_64 on the dedicated emulator. Physical phones, other Android versions/ABIs, audio/haptics and device-specific graphics/safe areas remain unverified. Manifest minimum API 24 is not a tested compatibility range.

After developer-approved release preparation, download only the separately signed `TomorrowsYou-v0.1.0-alpha.2-android.apk` and matching checksum. Verify its SHA-256 before installation. Do not uninstall or clear an existing debug app to resolve a signing conflict; release updates require the same package and signing identity.

No public publication is authorized. Do not mark this candidate ready until the actual signed APK passes Android runtime QA and its source, version, certificate, non-debuggable status, package ID, size and checksum are recorded.
