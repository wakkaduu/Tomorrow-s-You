# TOMORROW'S YOU — Android Alpha 0.1.0-alpha.2

**Early Android alpha — expect rough edges.** TOMORROW'S YOU is a temporal puzzle game: record your own past attempts as Echoes, then cooperate with them to solve each room.

## What is included

- Ten campaign levels across five difficulty tiers.
- Echo recording and playback. Echoes expire, and they hold pressure plates to open doors.
- A limited number of WAIT actions per level.
- The MORROW facility-AI narrative, with opening and closing transmissions.
- The Incident Archive (31 records), daily hints and local save progress.
- Fully offline play. The APK declares no permissions.

## Known testing limitations

- Runtime testing was done only on one Android 15 (API 35) x86_64 **emulator**. Physical Android devices and ARM (arm64/armv7) execution are **unverified**, although the APK bundles ARM libraries.
- Some graphics configurations may fail. On the emulator's software renderer the game showed a blank screen, with logcat reporting "active uniforms exceed GL_MAX_FRAGMENT_UNIFORM_VECTORS". Devices with a low fragment-uniform limit may be affected. Real-hardware impact is not yet known.
- Audio, haptics and gesture/notch navigation are not fully tested.
- Some bugs may remain. Only the intended solution route of each level was played on Android.

## Fixes

- Android Back follows modal/menu navigation and requires an explicit Main Menu exit confirmation. Settings and Archive return to the same paused puzzle.
- Android selects OpenGL Compatibility automatically. Temporal backgrounds, holographic effects, particles, UI glow and Echo trails are retained. This avoids the reproduced emulator Vulkan presentation failure; Vulkan itself is not claimed universally fixed.
- Current-solution scoring counts committed Echo recordings plus the active attempt. Discarded attempts and completed-level replays reset correctly, while slower runs preserve historical best results.
- Live board resizing remaps actor visuals, interpolation targets and trails without changing logical positions, turns or recordings.

## Validation

Source tests passed: 19 suites, including 86 targeted regression checks, all ten campaign solutions, 3,187 turn/WAIT checks, 20 hint tests and 15 release-helper tests.

On the signed APK (Android 15/API 35 x86_64 emulator, OpenGL ES 3 Compatibility, offline), all four fixes above were verified at runtime. All ten levels were completed with their intended solutions for 30/30 stars. Echo expiry, door synchronisation, WAIT limits, hints, Archive, Back navigation, live resizing, backgrounding, force-stop persistence and explicit exit passed. No crash or ANR was seen. The alpha.1 upgrade path was also tested. The manifest's declared minimum API (24) is not a tested range. Known balance limitations: movement-loop WAIT alternatives and Nightmare's two-Echo shortcut. Campaign data, narrative, WAIT budgets and save schema 3 are unchanged.

## Installation and feedback

Use only `TomorrowsYou-v0.1.0-alpha.2-android.apk` and its matching `.sha256` asset. Verify the checksum before installing. A same-package/same-key alpha.1 update preserved the emulator's progress and hint disclosures. If a personal debug installation has a different signature, do not uninstall or clear its data to resolve the conflict.

Report device model, Android version, level and reproduction steps. Detailed results: [QA report](https://github.com/wakkaduu/Tomorrow-s-You/blob/main/docs/ALPHA_RELEASE_QA.md), [fix report](https://github.com/wakkaduu/Tomorrow-s-You/blob/main/docs/ALPHA2_FIX_REPORT.md).
